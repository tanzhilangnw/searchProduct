# LQA Radar · 出海文案体检（原型）

调研报告推荐方向的**可运行原型**：把本地化文案的提审前检查，从「人工逐条抽检」变成「导入 → 扫描 → 问题清单 → 一键修复 → 导出报告」。

## 运行

```powershell
cd projects/game/prototype
python -m http.server 8130
# 打开 http://127.0.0.1:8130/
```

纯前端，零依赖，不调用任何付费 API。也可以直接双击 `index.html`（`file://`）打开。

## 它能做什么

- **导入**：CSV 长表（`key,locale,source,target,maxLen,context`），或点「加载示例项目」
- **扫描 10 类问题**：缺失翻译、未翻译、占位符不一致、富文本标签、文本溢出、接近上限、术语不一致、标点/全半角、空格、中文残留
- **结果**：可上线度（0–100）、阻塞/高危/中危/提示四级、按语言/级别/关键词筛选
- **修复**：占位符、标点、空格、术语、闭合标签可一键修，修完自动重扫
- **报告**：导出 Markdown，直接贴进提审单/群聊

## 示例数据

内置《灵石纪元》出海版：38 个 key × EN/JA/KO = 114 条文案，故意埋了 32 个问题，覆盖 10 种类型。
初始可上线度 **71/100**，6 个阻塞项。

## 实测

- Playwright + 本机 Chrome：0 page error / 0 console error
- 114 条扫描、一键修复、CSV 导入、Markdown 导出、移动端 390px 均已跑通
- 截图在 `shots/`

## 生产版可以怎么接

原型用确定性规则，保证离线可跑、结果可复现。生产版建议：

1. 规则引擎保底（与本原型一致）
2. 可选 LLM：术语候选抽取、语气/角色口吻、文化语境、翻译质量估计
3. 文件适配：JSON / XLIFF / Unity CSV / 自研后台导出
4. 团队能力：术语表共享、项目历史、提审报告归档
