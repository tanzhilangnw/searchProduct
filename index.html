五、如果只选一个 + 第一周做什么

今天没有可以「选一个」的方向。所以这条给的是「怎么找」。

用四问砍你自己的行业

1. 客户是能自己拍板付钱的个体老板吗？
个体老板 ✓ / 大公司采购 ✗ / 消费者 ✗ / 某职业员工 ⚠ 改卖给他老板
2. 他现在怎么解决的？
Excel+微信+雇人 ✓ / 已有好用软件 ✗ / 没意识到是问题 ✗
3. 这活一周做几次？
每天 ✓ / 每周 1-2 次 ⚠ / 每月不到 1 次 ✗
4. 雇人做要多少钱？软件收 1/10 合理吗？
例：雇教务 5000/月 → 软件 300~800/月。算不出来 = 痛点不够痛。

第一周做什么

  1. 选一个你熟悉或有熟人的行业（这是唯一我不需要你写代码、我也帮不上的部分）
  2. 找 3 个老板聊，不是员工，不是朋友的朋友，是真在经营的人
  3. 问一句：「这件事你现在谁在做？一个月花多少钱？」
  4. 验证标准：他愿不愿意先付 500 定金试做。愿意 = 真需求；不愿意 = 换行业

⚠️ 为什么不是「写个 MVP 试」：9 轮证明，我能在数据里判断的东西已经到头了。 剩下的信息只在老板嘴里。先问，再写代码，顺序不能反。
